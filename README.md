# AR-паспорт оборудования (ЛР №4)

Веб-AR на **MindAR 1.2.5 + A-Frame 1.5.0**. Наводите телефон на маркер-табличку: над ней появляется 3D-модель оборудования с индикатором состояния и карточкой, а внизу экрана — панель с данными.

- Модель **закрепляется**: если убрать камеру с маркера, она остаётся на экране, и панель тоже.
- Новый маркер сменяет модель и панель. Отсканированное оборудование собирается в кнопки под панелью.
- **Один палец** сдвигает модель, **два пальца** меняют её размер. Панель закрывается кнопкой ✕.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | AR-страница |
| `machines.json` | данные об оборудовании (меняются без правки кода) |
| `markers/lathe.png`, `mill.png`, `printer.png` | маркеры-картинки |
| `markers_print.pdf` | маркеры для печати, по одному на лист A4, сторона 12 см |
| `targets.mind` | маркеры, «скомпилированные» для MindAR (собирается на `compile.html`) |
| `compile.html` | страница, которая собирает `targets.mind` из картинок |
| `make_markers.py` | рисует маркеры-картинки и PDF |

## Первый запуск: собрать targets.mind (один раз)

1. Опубликуйте проект (`git push`) и откройте `https://<логин>.github.io/<репозиторий>/compile.html`, или локально `python3 -m http.server 8000` → `http://localhost:8000/compile.html`.
2. Нажмите **«Собрать targets.mind»**, подождите 10–60 секунд, файл скачается.
3. Положите `targets.mind` в папку проекта рядом с `index.html` и опубликуйте:
   ```bash
   git add targets.mind
   git commit -m "targets.mind"
   git push
   ```

Запасной вариант: онлайн-компилятор MindAR https://hiukim.github.io/mind-ar-js-doc/tools/compile. Загрузите `lathe.png`, `mill.png`, `printer.png` **именно в этом порядке**.

## Запуск

- **Телефон:** `https://<логин>.github.io/<репозиторий>/`. Камера работает только по HTTPS.
- **Компьютер:** в папке проекта `python3 -m http.server 8000 --bind 127.0.0.1` → `http://localhost:8000`.

Маркер показывайте с экрана компьютера (`markers/*.png` на весь экран) или распечатайте `markers_print.pdf` в масштабе 100%.

## Данные

Отредактируйте `machines.json`, даты пишутся как `ГГГГ-ММ-ДД`. Состояние вычисляется само: `"repair": true` даёт «На ремонте», прошедшая дата `nextTO` даёт «Требуется ТО», иначе «Исправен».

## Если не работает

| Симптом | Причина |
|---|---|
| «Нет файла targets.mind» | не собран или не опубликован `targets.mind` |
| «Камера недоступна» | не дано разрешение или адрес не `https` |
| «Не удалось загрузить machines.json» | страница открыта двойным щелчком, а не через сервер |
| Маркер не находится | маркер слишком мелкий, бликует или далеко; держите 20–40 см |
| Модели других маркеров не меняются после пересоздания картинок | после `make_markers.py` нужно заново собрать `targets.mind` |
